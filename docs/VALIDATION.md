# 2026-11-06 验证记录

这是可运行开发首版的验证，不代表所有 B 站页面兼容，也不是稳定发布声明。

## 模拟页面回归

`npm test` 完全拦截 B 站网络，加载本地定义的页面、真实 672×378 AVIF 封面和 Canvas `captureStream` 视频。结果由测试写入 `mock-results.json`；截图在 `screenshots/mock-*`。模拟视频证明浏览器媒体时间与 DOM 生命周期逻辑，不能证明 B 站视频资源可用。

覆盖三主题 × 首页/搜索/详情九组封面截图及尺寸断言；视频实际进度增长；同一个 iframe 放大/还原/Esc/遮罩；评论更新不移除播放节点；异步 Shadow DOM 评论、楼中楼和图片链接导出；播放器重试；图片重复打开/关闭；隐藏媒体销毁与恢复不自动播放；单实例与关闭；搜索子域跨源消息协作与拒绝错误 origin/source；新搜索停止旧播放、延迟响应取消、空结果、HTTP 500、排序与翻页；中文输入法事件；390px 深色导航；恢复原版、重复初始化和页面异常。

`npm run test:unit` 直接打包并导入实际适配器和消息桥：URL 安全检查、分 P、绝对分区 URL 不重复拼接域名、消息来源/窗口/令牌/类型检查。

## 真实 B 站

命令 `npm run test:live` 使用未登录 Chromium，访问真实首页、搜索子域和普通视频页。没有拦截媒体/站点页面，没有提交任何评论、点赞、关注或收藏。用户脚本管理器接口使用浏览器上下文的 HTTP 客户端模拟，未读取或导出 Cookie；真实扩展管理器的权限弹窗与沙箱仍待单独验收。

本次成功采样（详细 URL、时间与失败请求在 `live-results.json`）：

| 真实路径 | 采集卡片 | 放大前进度 | Esc 后进度 | iframe 相同 |
| --- | ---: | ---: | ---: | --- |
| 首页 | 14 | 0.815s | 2.765s | 是 |
| search.bilibili.com 搜索 | 45 | 0.673s | 1.974s | 是 |
| 普通视频详情 | 1 | 0.593s | 2.247s | 是 |

每条路径有企业微信/钉钉/飞书截图 `screenshots/live-{home,search,detail}-{wecom,dingtalk,feishu}.png`，另有气泡播放截图。采样中无 `pageerror`；网络日志保留了三次失败请求，不能据此保证所有资源或所有视频正常。

先前检查遇到两个真实边界：推荐视频跳转 `/festival/S16` 后不符合受限桥路径，按设计超时并保留原版入口；搜索 API 返回 HTTP 412。因此加入仅匹配当前原站关键词/排序/页码的 DOM 回退；主动新搜索不能复用旧结果。最终搜索子域记录是使用原站已加载卡片后的真实播放成功，不是绕过 412。

## 尚未完成的全面验收

- 登录后的评论发布不在首版实现内，明确回退原版；从未为测试自动发送。
- 真实评论懒加载、更多楼中楼展开和图片预览尚未在多种真实评论结构中全面验证；模拟 Shadow DOM 与异步取消有覆盖。
- 所有分区、特殊活动视频、番剧、付费/地区内容、全屏所有浏览器实现、真实脚本管理器扩展、Firefox/Safari 仍未全面验证。
- 网络或风控导致的新搜索/排序/翻页需要点“在原站加载后继续”；不能将失败的接口请求宣称为完整无刷新搜索成功。

源码中不包含生产演示视频或模拟评论；所有模拟数据仅在 `tests/fixtures`。
