# 验证记录

## 模拟页面回归

`npm test` 在 Chromium headless 中运行，检查：真实尺寸图片的 16:9 封面比例、消息内播放器挂载、放大/还原与 Esc 不替换 iframe、主题热切换、空搜索状态。截图输出为 `docs/qa-home.png`。

## 真实站点边界

本首版没有把静态模拟截图当作真实 B 站播放证据。真实 B 站播放需要在用户自己的登录/网络环境中点击气泡播放；iframe 由 B 站原生页面负责，可能受 CSP、登录、地区、编码和风控限制。未进行自动评论、点赞、关注、收藏或下载。

## 已覆盖与未覆盖

已覆盖：三主题 token、浅深色设置、搜索 Enter/空结果/翻页模型、旧请求 AbortController、单播放器资源清理、隐藏媒体暂停消息、评论楼中楼渲染、16:9 封面布局、窄窗口导航入口。

未覆盖：真实站点跨域播放成功率、真实 Shadow DOM 评论抓取、所有 B 站分区 DOM、真实登录后发布评论、Safari/Firefox 移动端，以及浏览器阻止自动播放时的每种提示文案。
