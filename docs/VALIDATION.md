这是可运行开发首版的验证，不代表所有 B 站页面兼容，也不是稳定发布声明。

## 模拟页面回归

`npm test` 完全拦截 B 站网络，加载本地定义的页面、真实 672×378 AVIF 封面和 Canvas `captureStream` 视频。结果由测试写入 `mock-results.json`；截图在 `screenshots/mock-*`。模拟视频证明浏览器媒体时间与 DOM 生命周期逻辑，不能证明 B 站视频资源可用。

覆盖三主题 × 首页/搜索/详情九组封面截图及尺寸断言；视频实际进度增长；同一个 iframe 放大/还原/Esc/遮罩；评论更新不移除播放节点；异步 Shadow DOM 评论、楼中楼和图片链接导出；播放器重试；图片重复打开/关闭；隐藏媒体销毁与恢复不自动播放；单实例与关闭；搜索子域跨源消息协作与拒绝错误 origin/source；新搜索停止旧播放、延迟响应取消、空结果、HTTP 500、排序与翻页；中文输入法事件；390px 深色导航；恢复原版、重复初始化和页面异常。

## 封面地址兼容（0.1.2）

真实热门接口的 pic 字段返回 `http://i0.hdslb.com/...`，旧版通用 safeURL 只接受 HTTPS，导致图片地址变为空。新增仅对 hdslb.com 及其子域升级 HTTP 的 imageURL，通用导航地址校验不变。DOM 封面读取兼容 data-src、picture/source/srcset，并跳过 data: 占位图；无地址和加载失败时隐藏 img，避免破图和 alt 文案露出。

单元检查覆盖 CDN HTTP 升级、协议相对地址、HTTPS 保留和伪造 CDN 域名拒绝。模拟回归使用 HTTP API pic、data-src 占位图和 picture/source 三类来源，逐一解码全部封面并检查尺寸。实际热门接口返回的 HTTP 封面改为 HTTPS 后，独立无 Cookie 请求得到 200 image/jpeg。此项实际网络检查不代表所有视频封面持续可用。

## 首页自动翻页修复

首页采集到原站卡片后原先把总页数固定为 1，导致三主题的首页都不能触发续页。现在首屏保留原站推荐，续页从已有热门接口第 1 页开始，并在列表显示“继续浏览 · 热门视频”。这不是继续拉取个性化推荐。分页追加不重建播放 iframe，页码和按钮状态同步更新。初次渲染、追加完成与窗口调整都会检查是否接近底部；隐藏的聊天不会自动加载。失败可点按钮重试，空页、接口末页或连续两页无新增视频时停止请求。分区仍只采集已有原站卡片，不推断分区续页接口。

新增三主题首页触底、失败重试、首个续页不跳页、连续续页去重、更新页码、末页停止、保留播放 iframe 和来源说明的模拟回归；另覆盖企微首屏不足一屏时主动加载，以及连续重复数据停止请求。
